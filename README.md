## 글을 남길 곳

- [질문](https://github.com/gityeop/hannyeong-community/discussions/categories/%EC%A7%88%EB%AC%B8): 설치, 오른쪽 ⌘, 앱별 기본 표시 등 사용법이 궁금할 때
- [개선 제안](https://github.com/gityeop/hannyeong-community/discussions/categories/%EA%B0%9C%EC%84%A0-%EC%A0%9C%EC%95%88): 사용하면서 불편했던 점과 원하는 동작을 제안할 때
- [설정·활용](https://github.com/gityeop/hannyeong-community/discussions/categories/%EC%84%A4%EC%A0%95-%ED%99%9C%EC%9A%A9): 앱별 설정이나 자신에게 맞는 사용 방법을 공유할 때
- [공지](https://github.com/gityeop/hannyeong-community/discussions/categories/%EA%B3%B5%EC%A7%80): 업데이트와 주요 변경 안내를 확인할 때

개선 제안에는 어떤 앱에서 어떤 작업을 하다가 불편했는지 함께 적어 주세요.

입력이 잘못 바뀌거나 동작에 문제가 있다면 [버그 제보](https://github.com/gityeop/hannyeong/issues)에 남겨 주세요. 한녕·macOS 버전, 사용한 앱, 예상한 결과와 실제 결과를 함께 적어 주세요.

글을 쓰거나 댓글에 참여하려면 GitHub 로그인이 필요합니다. 입력 예문은 공개해도 되는 내용으로 적어 주세요.
