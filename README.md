# 한녕 커뮤니티

한녕을 쓰며 궁금한 점, 있었으면 하는 기능, 사용 경험을 나누는 공간입니다.

**[커뮤니티 참여하기 →](https://github.com/gityeop/hannyeong-community/discussions)**

## 어떤 글을 남기면 되나요?

- [질문 · Q&A](https://github.com/gityeop/hannyeong-community/discussions/categories/q-a): 설치, 설정, 사용법을 물어보세요. 도움이 된 답변은 답변으로 채택할 수 있습니다.
- [기능 제안 · Ideas](https://github.com/gityeop/hannyeong-community/discussions/categories/ideas): 있었으면 하는 기능을 제안하고, 공감하는 제안에 👍를 눌러 주세요.
- [이야기 · General](https://github.com/gityeop/hannyeong-community/discussions/categories/general): 사용 소감과 의견을 나눠 주세요.
- [활용 공유 · Show and tell](https://github.com/gityeop/hannyeong-community/discussions/categories/show-and-tell): 나만의 설정이나 활용 방법을 소개해 주세요.
- [공지 · Announcements](https://github.com/gityeop/hannyeong-community/discussions/categories/announcements): 커뮤니티 안내를 확인할 수 있습니다.

글을 쓰거나 댓글·투표에 참여하려면 GitHub 로그인이 필요합니다.

## 버그를 발견했다면

버그는 기존 [한녕 Issues](https://github.com/gityeop/hannyeong/issues)에 알려 주세요. 한녕 버전, macOS 버전, 문제가 발생한 앱, 재현 순서를 함께 적어 주시면 확인에 도움이 됩니다.

## 함께 지켜 주세요

- 서로 존중하며 이야기해 주세요.
- 질문이나 제안을 올리기 전에 비슷한 글이 있는지 찾아봐 주세요.
- 비밀번호, 개인정보, 회사 내부 문서 등 공개하면 안 되는 내용은 올리지 말아 주세요. 입력 문제를 설명할 때는 공개해도 되는 예문을 사용해 주세요.
